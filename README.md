# Autism Kids Predictability Board

A Home Assistant custom integration for autism-friendly dashboards focused on predictability, communication, and transitions.

## Features

- Home Status Board for Predictability
- Nonverbal Request Buttons
- Visual Countdown Timer Board
- Config flow and options flow
- HACS custom repository support

## HACS install

1. Add this repository to HACS as a custom repository.
2. Select **Integration**.
3. Install the integration.
4. Restart Home Assistant.
5. Add **Autism Kids Predictability Board** from Devices & Services.

## Manual install

Copy `custom_components/autism_kids` into your Home Assistant `custom_components` folder, restart Home Assistant, then add the integration.

## Notes

HACS support in this repo uses `hacs.json` at the repository root.
