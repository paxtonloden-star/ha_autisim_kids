# Autism Kids Predictability Board

A Home Assistant custom integration for autism-friendly dashboards focused on predictability, communication, and transitions.

## Included modules
- Home Status Board for Predictability
- Nonverbal Request Buttons
- Visual Countdown Timer Board
- Feelings Station
- Calm Corner
- Visual Calendar
- Social Story Board

This version creates integration-owned editable values directly instead of requiring manual helpers for dinner text, special change text, bedtime, school-tomorrow, calm steps, visual calendar text blocks, and social story steps.
